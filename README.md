## How I Work

```mermaid
flowchart LR
    A[Talk to users] --> B[Scope and BRD]
    B --> C[Spec and wireframes]
    C --> D[Sprint with the team]
    D --> E[Ship]
    E --> F[Measure]
    F --> A

    style A fill:#02569B,stroke:#fff,color:#fff
    style C fill:#0175C2,stroke:#fff,color:#fff
    style E fill:#00ADD8,stroke:#fff,color:#fff
```
